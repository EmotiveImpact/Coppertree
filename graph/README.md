# Information graph
universe.json is a portable graph of named entities and typed relationships, not a graph database or visual application. It can later power a searchable browser or graph database without changing stable IDs.

Entities: characters, supporting adults, places, books, objects, artwork and story events.
Relationships: lives_in, appears_in, leads, finds, contains, located_in, uncle_of, grandfather_of, friendship_dynamic, depicts, occurs_in.
Sequence records story order; release order lives in books/SERIES_PLAN.md. Development status is distinct from what happens inside a story.

Before accepting edits, ensure IDs are unique and every edge endpoint exists. Add source decision IDs and richer chapter/page references as material is drafted.
