# Production and continuity workflow

## Before each session
Read project state and decisions. Inspect current relevant source files and artwork. State any missing context rather than inventing it.

## For each new book
Brief -> emotional question -> plot -> page plan -> manuscript -> rough artwork -> continuity review -> final illustrations -> colouring and activity layout -> proof -> corrections -> final approved edition.

## Continuity review
Check names, hair, clothing references, relationships, geography, seasons, ages, object ownership and event order. Distinguish something a child imagines from something that happened. Ensure each child has agency beyond their hobby. Review text and art together.

## Colouring production
Use clear enclosed shapes, useful colouring areas and consistent readable outlines. Avoid unnecessary tiny details. Preserve natural hairstyles using colourable outlines rather than filling all hair as solid black. Keep text outside the main colouring area and check readability at actual print size. Select production specifications before layout.

## End of each work session
Update PROJECT_STATE.md, changed bible records, graph/universe.json, decisions/DECISIONS.md and the asset register. Record completed versus planned work, current versions, unresolved questions and next actions. Commit related changes together when a repository is connected. Store exported print files with explicit versions. Never overwrite source artwork destructively.

## Delivery limits
This system supports reliable resumption by reading saved records. It does not provide perfect recall, guarantee that an agent will retrieve files automatically, or run unattended between conversations. Each session must actively load and update the source of truth.
